# Yelp Dataset Analysis & Text-to-SQL Application

A big data analytics project built on the Yelp public dataset, covering exploratory data analysis, data enrichment with external sources, and a conversational Text-to-SQL web application.

## Project Overview

This project is divided into three main phases:

1. **Data Analysis & Visualization** — Business, user, review, rating, and check-in analysis using the Yelp dataset.
2. **Data Enrichment & Exploration** — Integrating external datasets (weather, demographics, geospatial, etc.) to validate hypotheses about restaurant behavior and review patterns.
3. **Text-to-SQL Conversational App** — A full-stack chat interface powered by an LLM that translates natural language questions into SQL queries against the Yelp database.

## Dataset

[Yelp Open Dataset](https://www.yelp.com/dataset) — includes businesses, reviews, users, check-ins, and photos across 10 metropolitan areas.
